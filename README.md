# Mining Operations Reporting Analysis

## Project Overview
This portfolio project explores how mining production reporting can be improved through data analysis, process mapping, and dashboarding.

The project uses synthetic practice data to demonstrate a possible workflow for analysing production achievement, equipment downtime, and reporting efficiency.

## Business Problem
Manual production reporting may involve repeated data entry, combining multiple shift files, correcting inconsistent figures, and delays in delivering reports to management.

## Objectives
- Analyse planned versus actual production.
- Calculate equipment downtime percentage.
- Examine reporting turnaround time and manual reporting effort.
- Map the current reporting process and propose an improved digital workflow.
- Present key performance indicators through a dashboard.

## Tools
- Excel
- Python
- SQL
- Power BI
- GitHub

## Project Workflow
1. Prepare and validate the practice dataset.
2. Calculate business KPIs.
3. Analyse the data using Python and SQL.
4. Document the as-is and proposed to-be processes.
5. Build a Power BI dashboard.
6. Summarise findings and recommendations.

## Data Disclaimer
All initial records and numerical examples are synthetic and intended for learning. They do not represent verified operational data from a real mine.
